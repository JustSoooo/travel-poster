# 旅行海报 travel-poster

把多年的照片，变成四张手机全屏海报（1206×2622，iPhone 17 Pro 尺寸，另附 2412×5244 超高清版）：

| 总海报 | 重访篇 | 年鉴篇 | 路线篇 |
|---|---|---|---|
| 去过几个国家、省、城市，世界足迹点阵图，每年出行次数 | 哪些城市一去再去，隔得最久的重逢 | 每年去了哪儿，时间轴上一趟一个点 | 照片位置按时间连起来的地面路线（中国 + 走得最多的两个国家） |

- **只读照片文件头**（拍摄时间、GPS、设备型号），不改照片、不上传，全部在本机完成
- 地图只到城市级，不画国界省界
- 两种用法：**电脑终端一键版**（Mac / Linux，照片在外接硬盘或电脑里）、**NAS Docker 版**（绿联等）

---

## 用法一：电脑终端一键版（Mac 推荐）

1. 插上放照片的硬盘
2. 打开「终端」（启动台搜索 “终端” / Terminal），粘贴下面这一行，回车：

   ```
   curl -fsSL https://github.com/JustSoooo/travel-poster/raw/main/tp.sh | bash
   ```

3. 按提示操作，一共两步：
   - **选照片在哪**：列出的硬盘里输入编号；或者把照片文件夹拖进终端窗口再回车。Mac 弹出「终端想访问可移除宗卷上的文件」→ 点 **允许**
   - **确认设备**：列出所有拍过照片的设备，别人的（家人、朋友发来的）会标 ⚠。直接回车 = 按建议；要改就输入编号

4. 完成后自动打开 **桌面/旅行海报**，里面 8 张图（4 张手机尺寸 + 4 张 @2x 超高清）

- 第一次会自动装好需要的东西（约 5–10 分钟，都在 `~/.travel-poster`，不动系统）；扫描十几万张照片约 20–60 分钟
- 以后再跑同一行命令，回车沿用上次的硬盘，只读新增的照片，几分钟出图
- 电脑里装了 Chrome 就直接用它截图；没装会下载一个约 150 MB 的
- 没有 Python 时会提示运行 `xcode-select --install`（苹果官方工具，弹窗点安装），装完再粘贴一次命令
- 下载了仓库的，也可以直接 `bash tp.sh /Volumes/你的硬盘`
- Linux 需要中文字体（如 `sudo apt install fonts-noto-cjk`）

不想要了：删掉 `~/.travel-poster` 文件夹即可（扫描结果、环境都在里面）。

## 用法二：绿联 NAS（Docker）

绿联 UGOS Pro，全程点鼠标 + 一次粘贴。支持绿联 DH 系列（ARM）和 DXP 系列（x86），其他能跑 Docker 的 NAS 也可以。

### 1. 下载镜像文件（约 1.4 GB）
本仓库右侧 **Releases → 最新版**：DH2300 / DH4300 Plus 等 **DH 系列**下载 `travel-poster-arm64.tar`；**DXP 系列**下载 `travel-poster-amd64.tar`。不确定型号：UGOS 设置 → 关于本机。

### 2. 导入
- UGOS 应用中心安装 **Docker**（装过就跳过）
- 把 `.tar` 上传到 NAS 任意位置 → Docker → 镜像 → 本地镜像 → 添加/导入 → 选这个文件

### 3. 建项目（关键：文件夹放对位置）
- 在 NAS 的**照片文件夹里**新建一个文件夹，名字叫 `travel-poster`
- Docker → 项目 → 创建：项目名称 `travel-poster`；存放路径**选刚建的 `travel-poster` 文件夹**；Compose 配置把 [`docker-compose.yml`](docker-compose.yml) 的内容**原样粘贴，不用改任何字** → 立即部署

> 工具会读取 `travel-poster` 的上一级，也就是你的照片文件夹（只读）。照片分散在好几个共享文件夹的，把 `travel-poster` 建在它们的共同上一级里。

### 4. 打开网页，点一下
浏览器打开 `http://NAS的IP:8090`，点 **一键生成海报**。第一次 30–60 分钟（可以关网页），完成后页面上直接出现四张图，点「全部下载」。

海报里出现了没去过的地方 → 展开「海报里出现了没去过的地方？」，只看橙色的设备，不是自己的选「别人」，点「保存并重新生成」。

## 常见问题

| 问题 | 原因 / 办法 |
|---|---|
| 页面提示「没找到照片文件夹」 | `travel-poster` 文件夹没建在照片文件夹里面：删掉项目，按第 3 步重建 |
| 扫描很慢 | 正常，ARM 机型十几万张约 1 小时；可以先关掉网页，回来再看 |
| 某一年特别少 / 某趟旅行不见了 | 那段时间的照片没有 GPS（老相机、关了定位），又没有同时用手机拍，系统无法知道你在哪 |
| 多出一趟没去过的地方 | 第 2 步里有别人的设备没排除，改成「别人」后重新生成 |
| 时间对不上 | 相机时钟没调对，这个版本不做相机时钟校准 |
| 路线篇是空的 / 很短 | 路线靠手机 GPS 连起来；那段路没用手机拍、或只坐飞机，就连不出来 |
| 终端版想从头重扫 | 删掉 `~/.travel-poster/data` 再跑一次命令 |
| 想放到公网访问 | 不建议：页面没有登录，能看到你的照片缩略图。只在家里局域网用 |

## 隐私
- 照片目录以只读方式挂载，程序不会修改、移动、删除任何照片
- 不联网上传任何数据；海报里只有城市级位置，不显示家的位置
- 扫描结果：NAS 版在 `data/` 文件夹，终端版在 `~/.travel-poster/data`，删掉即清空
