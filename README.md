# 旅行海报 travel-poster

把 NAS 里多年的照片，变成三张手机全屏海报（1206×2622，iPhone 17 Pro 尺寸）：

| 总海报 | 重访篇 | 年鉴篇 |
|---|---|---|
| 去过几个国家、省、城市，世界足迹点阵图，每年出行次数 | 哪些城市一去再去，隔得最久的重逢 | 每年去了哪儿，时间轴上一趟一个点 |

- **只读照片文件头**（拍摄时间、GPS、设备型号），不改照片、不上传，全部在 NAS 本机完成
- 地图只到城市级，不画国界省界
- 支持绿联 DH 系列（ARM）和 DXP 系列（x86），其他能跑 Docker 的 NAS 也可以

---

## 使用步骤（绿联 UGOS Pro，约 15 分钟 + 扫描时间）

### 1. 下载镜像文件
打开本仓库右侧 **Releases → 最新版**：
- DH2300 / DH4300 Plus 等 **DH 系列** → 下载 `travel-poster-arm64.tar`
- **DXP 系列** → 下载 `travel-poster-amd64.tar`

> 不确定型号：UGOS 网页右上角 **设置 → 关于本机** 看型号。

把下载的 `.tar` 文件上传到 NAS 任意文件夹（比如 `个人文件夹/下载`）。

### 2. 导入镜像
UGOS 打开 **Docker**（没有就去应用中心安装）→ **镜像** → **本地镜像** → **添加 / 导入** → 选上一步上传的 `.tar` 文件 → 等导入完成，列表里出现 `travel-poster:latest`。

### 3. 创建项目
Docker → **项目** → **创建**：
- 项目名称：`travel-poster`
- 存放路径：选一个文件夹（比如 `docker/travel-poster`），扫描结果和海报会存在这里
- Compose 配置：把仓库里的 [`docker-compose.yml`](docker-compose.yml) 内容整个粘进去，**只改一行**：
  ```yaml
  - /volume1/照片:/photos/照片:ro
  ```
  冒号左边换成你照片文件夹在 NAS 上的路径（文件管理里右键文件夹 → **属性** 能看到完整路径）。照片分散在几个文件夹就照格式多写几行，冒号右边统一以 `/photos/` 开头、名字随便起。末尾的 `:ro` 表示只读，别删。
- 点 **立即部署**。

### 4. 打开网页，三步出图
浏览器打开 `http://NAS的IP:8090`（和打开 UGOS 用的是同一个 IP），页面上按顺序点：

1. **开始扫描**：十几万张照片大约需要半小时到一小时，进度条走完就行，中途关掉网页不影响；以后加了新照片再点一次，只读新增的。
2. **确认设备**：列出照片里出现过的所有手机/相机。系统已经预选好，**重点看标成橙色「别人」的**：点「看样张」确认。
   - 别人微信、隔空投送发给你的照片带着对方的位置，不排除会凭空多出你没去过的地方
   - 家人的照片如果放在单独的文件夹，在「排除某些文件夹」里勾掉
   - 点 **保存**
3. **生成海报**：一两分钟出三张图，点「下载」或「全部打包下载」。想要更清晰的勾选「2 倍超清」。

旅程名字是按地名和节假日自动拼的（如「2025-10 国庆 喀什·塔什库尔干」），不满意可以在页面底部改，改完再点一次生成。

## 常见问题

| 问题 | 原因 / 办法 |
|---|---|
| 页面提示「没找到文件夹」 | 第 3 步的照片路径写错了，回到 Docker → 项目 → 编辑，改完重新部署 |
| 扫描很慢 | 正常，ARM 机型十几万张约 1 小时；可以先关掉网页，回来再看 |
| 某一年特别少 / 某趟旅行不见了 | 那段时间的照片没有 GPS（老相机、关了定位），又没有同时用手机拍，系统无法知道你在哪 |
| 多出一趟没去过的地方 | 第 2 步里有别人的设备没排除，改成「别人」后重新生成 |
| 时间对不上 | 相机时钟没调对，这个版本不做相机时钟校准 |
| 想放到公网访问 | 不建议：页面没有登录，能看到你的照片缩略图。只在家里局域网用 |

## 隐私
- 照片目录以只读方式挂载，程序不会修改、移动、删除任何照片
- 不联网上传任何数据；海报里只有城市级位置，不显示家的位置
- 扫描结果在 `data/` 文件夹，删掉即清空
